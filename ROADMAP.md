# Public project roadmap

This roadmap covers public twexapi-dev projects through 2027.

Security, compatibility, and maintainability take priority throughout every phase.

## Q3 2026

- Publish shared governance, review, contribution, and vulnerability policies in this repository.
- Align repository descriptions, topics, and READMEs with supported user tasks.
- Keep SDK OpenAPI, docs, and hub README in sync with shipped REST operations.
- Standardize npm packages on the `@twexapi-dev` scope.

## Q4 2026

- Enforce documented test, lint, and build checks across SDK and integration repos.
- Verify reproducible release artifacts where projects publish packages.
- Expand OpenSSF evidence tracking in [OPENSSF.md](OPENSSF.md).
- Improve agent integration docs for MCP, Skills, n8n, Prefect, Haystack, and Paperclip.

## 2027

- Close remaining OpenSSF Silver and Gold evidence gaps where applicable.
- Recruit additional maintainers with release and incident access.
- Grow independent contributors through scoped issues and documentation fixes.
