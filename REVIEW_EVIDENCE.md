# Two-person review evidence

Non-trivial changes in public twexapi-dev repositories should receive review from a person other than the author when practical.

Record evidence through:

- GitHub pull request reviews
- Required status checks on protected branches
- Release workflows that require maintainer approval

Link notable review evidence in repository release notes or security advisories when it affects public contracts.

Follow [REVIEWING.md](REVIEWING.md) for the review checklist.
