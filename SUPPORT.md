# Support

Use the affected repository's issue tracker for public support.

Include:

- Repository or package name
- Version, language, and install command
- Minimal reproduction or request and response shape
- Links to public docs or registry pages involved

Do not include API keys, credentials, cookies, private account data, or screenshots with private data.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md).

For TwexAPI REST behavior, start with [docs.twexapi.io](https://docs.twexapi.io).
