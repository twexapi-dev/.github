# OpenSSF Best Practices evidence register

This file tracks OpenSSF Best Practices evidence for public twexapi-dev projects.

Register projects at [OpenSSF Best Practices](https://www.bestpractices.dev/) when each repository is ready.

Do not claim a badge until the corresponding evidence is published on the default branch.

## Project tracking

Track per-repository badge status in GitHub issues in this repository.

Include:

- Repository name
- OpenSSF project URL when registered
- Current badge level target
- Missing criteria and owner
